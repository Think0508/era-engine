## 二、核心 UI 模式

### 1. 指令栏二层结构
- **Act_COM**（场景相关）：根据地点+在场角色+当前模式动态变化
  - 分类标签页：【★】/ [性骚扰] / [家务] / [剧本] / [自定义]
  - 推倒后整套替换为 H 指令集：[V] / [A] / [SM] / [侍奉] / ...
- **Ex_COM**（全局系统）：基本不变，跨场景稳定
  - 移动[400]、外出[405]、能力显示[803/804]、道具[490]、日历[993] 等
  - 只有少数项随模式变（如时停后出现 [999]结束时停）

### 2. 状态栏（顶部固定）
```
秋之月 9日(四) 10时33分（已时四点-小暑～）— 少云 —○ 气温20.0℃ 〈可吃饭〉
██████████████████████████████████ ( 9348/ 9348) [时间停止可] [常识改变发动可]
```
- 时间（月/日/星期/时辰）+ 天气 + 气温 + 状态提示
- 资源条（体力/气力/酒/精），彩色进度条
- 特殊状态标记：[时间停止可]、[催眠发动可]、[无法停止时间]

### 3. 地点感知枢纽（[811]所在地察觉）
- 列出所有 NPC：名字 + 关系标签([恋慕]/[思慕]/[安全]) + 位置编号 + 积攒度 + 睡眠状态 + 工作信息
- 可点击人名 → 直接导航到该角色所在地点
- 时停模式下变为「集合」界面（可多选带回本地点）

### 4. 数值变化可视化
每次互动后显示计算表：
```
你
快M    342    + 588    =  930
润滑    68    + 117    =  185
...
咲夜
快C      0    + 11829  = 11829
...
好感度 +60
体力-20 气力-20 （你）
+5分
```

### 5. 角色面板（多页签）
- 入口：[803]查看NPC / [804]查看主角 / 互动时点角色名
- 页签：[服装&能力] [经验&宝珠] [个人情报] [个人好恶] [身体情报] [陷落状态] [技能习得]
- 装备栏、素质分类（种族/性相关/身体/精神/技术/其他）、能力值网格（字母等级+数字）

### 6. 每日开场菜单（26号截图）
- 进入新天或读档后出现
- 顶部：资源条 + 自宅位置 + 起床时间
- 主菜单：睁开眼睛[100]、能力显示[101]、收集[105]、实绩解除[150]...
- 系统菜单：SAVE[200]、LOAD[300]、OPTION[400]...
- 实绩（成就）系统：里程碑式解锁（认识人数/好感度突破/技能等级）

### 7. 日历视图（23号截图）
- 显示未来一周每天的活动事件/宴会情报/工作
- 每天有主题标签（【中国风】【动物】【战斗】等）
- 特殊事件标注时间地点（如 19:00 迷途竹林永远亭赏月酒）

## 三、eraTW → 我们引擎的映射

| eraTW 概念 | 我们引擎的对应 | 实现方式 |
|-----------|--------------|---------|
| Act_COM 指令集 | location_commands + character_commands | plugin.toml `[ui]` 注册，按模式/条件过滤 |
| Ex_COM 指令集 | main_menu 指令 | plugin.toml `[ui].main_menu` 注册 |
| 指令集切换（推倒后） | 模式栈切换 | `enter_mode` effect → UI 按模式过滤指令 |
| 所在地察觉 [811] | 角色列表面板 | UI 插槽 `character-list`，数据来自 entity-system |
| 时间停止 | 全局模式 + 主题切换 | `enter_mode('time_stop')` → CSS 变量切换（蓝底） |
| 状态栏（顶部） | 固定顶栏组件 | `Statusbar.vue`，读 game-context + player entity |
| 数值变化表 | effect-system 输出格式 | 每个 effect 执行后记录 diff，渲染到叙事日志 |
| 角色面板多页签 | 角色详情组件 | `CharacterSheet.vue`，props 区分 player/npc |
| 每日开场菜单 | 游戏启动/读档后界面 | `game:new_day` 事件 → 模式切到 `daily_menu` |
| 日历 | 周计划视图 | quest-system 提供数据，专用日历组件渲染 |
| 调合/烹饪 | 技能使用界面 | ability-progression + inventory-system 协作 |
| 配方列表（按等级分组） | 技能等级过滤 | `abilities.getByTag` + 配方数据过滤 |
| 同行系统 | 角色 companion 状态 | 角色 `behavior.companion_of` 字段 |
| 实绩/成就 | 里程碑系统 | achievement 插件（未来） |
| 推进时间 | 行动耗时系统 | effect `advance_time` → game-context |
| 逆推（随机事件） | 条件触发随机事件 | `condition` + `random` 效果 |

## 四、eraTW 的布局结构总结

```
┌─────────────────────────────────────────────┐
│  状态栏（时间/地点/资源条/特殊状态）         │ ← 固定顶栏
├─────────────────────────────────────────────┤
│                                             │
│  NPC 信息条（名称/关系/状态/资源条）        │ ← 有NPC时显示
│                                             │
│  ▼ [Status] ─── [能力显示]                  │ ← 可折叠区块
│  你   体力 ████ 气力 ████ ...               │
│  NPC  体力 ████ 气力 ████ ...               │
│  情绪: ♥   理性: ★★★★★                     │
│                                             │
│  ▼ [Look] ─── [显示立绘] [显示设定]         │
│  ◆场景描述文本/口上                         │ ← 中央叙事区
│  [角色名]                                   │
│  [角色立绘]                                 │
│                                             │
├─────────────────────────────────────────────┤
│  ═══ Act_COM ═══ 【★】[家务]=[剧本]=...    │ ← 指令栏（可折叠）
│  会话[300]  泡茶[301]  身体接触[302] ...     │
│  ▼ Ex_COM ═══ [CONFIG]=...                  │ ← 系统指令栏
│  移动[400]  外出[405]  能力显示[803] ...     │
│  <上回指令: 移动>                            │ ← 上次指令提示
└─────────────────────────────────────────────┘
```

关键特征：
1. **全屏黑底**，无左右分栏（纯纵向堆叠）
2. **文本密集**，数值驱动，进度条彩色
3. **指令带编号**（键盘快捷键）
4. **可折叠区块**（[-] 折叠，展开显示详情）
5. **立绘居中**，角色名在立绘上方
6. **指令栏始终可见**（即使在叙事文本滚动时）
