# erArk 攻略/H系统 复刻参考文件夹

> 本文件夹是 erArk 游戏中**攻略→猥亵→H**全链路的系统设计文档集。
> 目标是为一款 TypeScript+Vue 类era引擎的复刻提供完整的系统结构、机制、公式、数值参考。
> 具体代码实现不在此范围内——但关键源文件已打包在 `src/` 中以备对照。

## 推荐阅读顺序（如果你是从零开始复刻）

1. **`00-公式手册.md`** — 理解数值体系和所有共享公式
2. **`01-核心H流程.md`** — 理解从日常→H的完整链路和前提体系
3. **`02~05`** — 理解服装/道具/射精/妊娠四个核心覆盖系统
4. **`06~08`** (浏览) — 看指令条目格式，了解某条指令怎么查
5. **`21-效果ID速查表.md`** — 看到效果ID时来这里查含义
6. **`09~17`** (按需要) — 实现具体子系统时查阅
7. **`18~22`** (按需要) — 补充系统
8. **`src/`** (按需要) — 需要看原始实现时对照

## 文档约定

- **公式引用**: 所有系统文档引用 `公式手册` 中的公式编号（如「见公式#1」）
- **效果ID**: 每条指令列出效果ID列表。通过 `21-效果ID速查表` 查含义。原始实现在 `src/Settle/default.py`
- **跨系统引用**: 用 `[系统名].md` 标注交叉依赖
- **数值**: 全部从代码/CSV中提取，不编造
- **角色称呼**: "主角"=玩家角色，"角色"=NPC
- **身体部位缩写**: B=胸, C=阴蒂, P=阴茎, V=阴道, A=肛肠, U=尿道, W=子宫, M=口喉
