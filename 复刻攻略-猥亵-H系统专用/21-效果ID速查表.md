## 11. CVE 综合数值结算

格式: `CVE_A{X}_{E|F|T|J|S}|{id}_G_{threshold}` 或 `CVE_A{X}_{E|F|T|J|S}|{id}_L_{threshold}`

| 前缀 | 含义 |
|------|------|
| `A1` | 角色=自己 |
| `A2` | 角色=目标 |
| `E` | 经验 (experience) |
| `F` | 好感度 (favorability) |
| `T` | 素质 (talent) |
| `J` | 宝珠 (juel) |
| `S` | 状态值 (status) |
| `G_` | 大于等于 (≥) |
| `L_` | 小于等于 (≤) |

例: `CVE_A2_E|80_G_1` = "若目标经验[80] ≥ 1, 则执行后续效果(通常是加好感/状态)"
