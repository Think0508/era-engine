# 道具系统

> 本文档描述H中使用的药物/道具/玩具的装备、效果、持续时间和expiration机制。
> 引用的核心公式见 [00-公式手册].md。

## 1. Body_Item 槽位映射

存储在 `BODY_H_STATE.body_item: Dict[int, list]`，15槽，每槽格式 `[item_name, has_item, end_time]`:

| 槽 | 物品ID | 名称 | 类型 | 行为ID |
|----|--------|------|------|--------|
| 0 | 122 | 乳头夹 | 2(猥亵兼H装备) | nipple_clamp |
| 1 | 123 | 阴蒂夹 | 2 | clit_clamp |
| 2 | 125 | V震动棒 | 2 | second_vibrator_insertion |
| 3 | 125/126 | A震动棒 | 2 | second_vibrator_insertion_anal |
| 4 | 133 | 搾乳机 | 1(仅H装备) | milking_machine |
| 5 | 134 | 采尿器 | 1 | urine_collector |
| 6 | 132 | 眼罩 | 1 | patch |
| 7 | 129 | 肛门拉珠 | 1 | second_anal_beads |
| 8 | 106 | 持续性利尿剂 | 0(药剂) | diuretics |
| 9 | 107 | 安眠药 | 0 | second_sleeping_pills |
| 10 | 108 | 排卵促进药 | 0 | ovulation_promotion_drugs |
| 11 | 101 | 事前避孕药 | 0 | second_birth_control_pills_before |
| 12 | 102 | 事后避孕药 | 0 | birth_control_pills_after |
| 13 | 120 | 避孕套 | 0 | condom |
| 14 | 140 | 口球 | 0 | gag |

**类型说明**:
- **0 (药剂)**: 有持续时间, 到期自动失效
- **1 (仅H装备)**: 仅在H场景内使用, H结束自动移除
- **2 (猥亵兼H装备)**: H内外均可装备(乳头夹/阴蒂夹/震动棒)

## 3. 道具/玩具效果

### 3.1 避孕套 (ID 120, 槽13)


## 4. 道具有效期管理

### 4.1 H内过期检查

每个指令循环中检查所有15槽:
```python
if body_item[i][1] and now_time > body_item[i][2]:
    body_item[i][1] = False  # 过期
    body_item[i][2] = None
```

### 4.2 非H过期检查

仅检查槽8(持续性利尿剂)和槽9(安眠药)。

### 4.3 道具清除效果

| 效果ID | 名称 | 清除范围 |
|--------|------|---------|
| 910 | ITEM_OFF | 自己全部15槽 |
| 915 | TARGET_ITEM_OFF | 目标全部15槽 |
| 926 | ITEM_OFF_EXCEPT_PILL | 除药剂(8-12)外全清 |
| 927 | TARGET_ITEM_OFF_EXCEPT_PILL | 同上, 目标 |
| 928 | TARGET_B_ITEM_OFF | 槽[0,4] (乳头夹+搾乳机) |
| 929 | TARGET_A_ITEM_OFF | 槽[3,7] (A震动棒+拉珠) |

## 5. UI 体现

- **H指令面板**: 药物/道具作为 SEX→DRUG 和 SEX→ITEM 子类的指令出现
- **角色信息栏**: 装备中的body_item在角色状态中显示(如"震动棒:强")
- **射精面板**: 射精时若装备避孕套 → 捕获精液量单独显示
- **性玩具遥控**: `sex_toy_level` 通过UI面板调整(0/1/2/3), 控制所有 type-2 道具强度
- **全局UI概览**: 见 [公式手册 §7](./00-公式手册.md#7-ui-上下文总览)
