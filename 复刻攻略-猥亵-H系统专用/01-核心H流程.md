# 核心H流程

> 本文档描述从日常互动→攻略→猥亵→H邀请→H内→结束H→结算的完整系统链路。

---

## 1. 系统概述

核心H流程是游戏的主行为回路。玩家的每个指令都经过相同的管道：**指令选择 → 行为设定 → 行为结算（事件+效果） → 实时变化 → 完成判断**。

### 1.1 引入/依赖的核心子系统

```
核心H流程依赖:
  ├── [00-公式手册].md  (所有计算公式)
  ├── [02-服装系统].md  (脱衣/穿回条件)
  ├── [03-道具系统].md  (润滑油/避孕套/玩具效果)
  ├── [04-射精系统].md  (射精量/精液位置/吸收)
  ├── [05-妊娠系统].md  (受孕判定/孕期)
  ├── 指令面板系统     (Script/System/Instruct_System/)
  ├── 前提系统         (Script/Design/handle_premise/)
  ├── NPC AI系统       (Script/Design/handle_npc_ai.py)
  ├── 结算系统         (Script/Design/settle_behavior.py + Script/Settle/)
  └── 口上系统         (Script/Design/talk.py)
```

## 3. 核心玩法链路（玩家视角）

**关键阈值**:
- 好感 LV≥3 (1000+) → 猥亵面板解锁
- 陷落 LV≥1 → H邀请成功率高


## 5. 指令执行流程

### 5.1 完整管道

```
1. 玩家点击指令
   ↓
2. handle_instruct.py → handle_instruct(instruct_id)
   - 从 constant.handle_instruct_data 查找处理函数
   - 执行函数: 设置 behavior.behavior_id, behavior.duration, target_character_id
   ↓
3. character_behavior.py → character_behavior(0)
   - 处理特殊模式(H/睡眠/等待)
   - judge_character_status()
     ├── handle_event(event_before_instruct)
     ├── settle_behavior.handle_settle_behavior()
     │     └── handle_instruct_data(behavior_id)
     │           ├── 查 config_behavior_effect_data[behavior_id] → 效果ID列表
     │           └── 逐个调用 settle_behavior_effect_data[effect_id](...)
     │                 └── 累加到 CharacterStatusChange
     ├── handle_event(event_after_instruct)
     ├── realtime_settle.character_aotu_change_value()
     └── handle_talk() → 口上文本
   - judge_character_status_time_over() → 标记行为完成

```

## 6. 口上系统框架

口上是行为结算后显示的对话/描述文本。

### 6.1 触发链

```
settle_behavior.py → talk.handle_talk(character_id)
  ├── handle_talk_sub(): 三层匹配构建候选集
  ├── choice_talk_from_talk_data(): 加权随机选择
  └── handle_talk_draw(): 文本渲染(占位符展开)
```

### 6.2 三层匹配

| 层级 | 来源 | 优先级倍率 |
|------|------|-----------|
| 通用口上 | `adv_id == 0` | ×1 |
| 角色专用口上 | `adv_id == character.adv` | ×10 (默认) |
| 目标专用口上 | `adv_id == target.adv` | ×10 (默认) |
| 特殊情境匹配 | 时停/女儿/爱情旅馆/浴室/隐奸等 | ×5 (默认) |

### 6.3 加权随机选择

```
1. 每条候选通过premise字符串逐条件评估 → 累加权重
2. 非 high_ 前缀的premise权重全部摊平为1（避免上下文淹没通用文本）
3. CVP权重可固定 (CVP_..._Weight|0_N)
4. 最终: 按权重区间 → 加权随机选一个区间 → 区间内均匀随机选一条
5. 若选中通用口上(adv==0) 或 权重<100: 有概率 fallback到纸娃娃地文
```

### 6.4 纸娃娃地文（占位符替换）

```
talk_text = '{behavior_id}' → talk_common_judge() 逐层替换:
  {vagina}  → 权重随机选一条阴道完整描述
  {vagina_s} → 权重随机选一条阴道简短形容词
  {penis_in_body_0} → 阴茎在体内的动作描述片段

替换后 → .format() 展开变量: {Name}, {TargetName}, {SceneName}, {TargetUpClothName} 等
```
