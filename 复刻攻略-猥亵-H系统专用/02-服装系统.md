## 2. 穿着/脱卸状态机

### 2.1 三层存储流转

```
身体穿着 (cloth_wear) ←→ 临时脱下 (cloth_off)
身体穿着 (cloth_wear)  → 浴室储物柜 (cloth_locker_in_shower)
浴室储物柜             → 宿舍衣柜 (cloth_locker_in_dormitory)
宿舍衣柜               → 身体穿着 (cloth_wear)
```

### 2.2 H中脱衣/穿回

**脱衣** (H中自动执行，效果ID常量):
```python
# 部分脱衣: 上衣(5)+胸衣(6) → cloth_off
UP_AND_BRA_TO_TEM / TARGET_UP_AND_BRA_TO_TEM

# 部分脱衣: 下衣(8)+内裤(9) → cloth_off
DOWN_AND_PAN_TO_TEM / TARGET_DOWN_AND_PAN_TO_TEM

# 全裸: 所有槽位 → cloth_off
WEAR_CLOTH_OFF
```

**穿回** (H结束/手动):
```python
# 从 cloth_off 穿回
SELF_CLOTH_BACK     → cloth_off → cloth_wear (自己)
T_CLOTH_BACK        → cloth_off → cloth_wear (目标)
SCENE_ALL_CHARACTERS_CLOTH_BACK → 全场穿回
```

## 3. H前提中的服装检查

### 3.1 关键前提ID

| 前提ID | 检查 | 用途 |
|--------|------|------|
| `CLOTH_OFF` | 全裸(除项圈/戒指外全空) | 全裸场景 |
| `NOT_CLOTH_OFF` | 未全裸 | — |
| `CLOTH_MOST_OFF` | 大致全裸(槽5,6,8,9全空) | 大部分插入指令 |
| `NOT_CLOTH_MOST_OFF` | 未大致全裸 | — |
| `TARGET_WEAR_PAN` / `TARGET_NOT_WEAR_PAN` | 目标是否穿内裤(槽9) | **插入V/A/U的前置** |
| `TARGET_WEAR_BRA` / `TARGET_NOT_WEAR_BRA` | 目标是否穿胸衣(槽6) | 胸部露出指令 |
| `TARGET_WEAR_IN_UP` / `TARGET_NOT_WEAR_IN_UP` | 目标是否穿上衣(槽5) | 上半身指令 |
| `TARGET_WEAR_IN_DOWN` / `TARGET_NOT_WEAR_IN_DOWN` | 目标是否穿下衣(槽8) | 下半身指令 |
| `WEAR_SKIRT` / `TARGET_WEAR_SKIRT` | 是否穿裙子(标签5) | 裙子相关指令 |
| `SHOWER_CLOTH` / `NOT_SHOWER_CLOTH` | 是否穿浴巾 | 浴室场景 |
| `SLEEP_CLOTH` | 是否穿睡衣 | 睡眠场景 |

### 3.2 身体部位 → 遮挡服装映射

| 身体部位 | 遮挡的槽位 |
|---------|-----------|
| 胸部 | 5(上衣) 或 6(胸衣) — 两者都脱才暴露 |
| 下半身 | 8(下衣) 或 9(内裤) — 两者都脱才暴露 |
| 手 | 7(手套) |
| 阴部/臀/肛/尿道 | 9(内裤) — **必须脱内裤才能插入** |
| 脚 | 11(鞋子) |

### 3.3 异常服装状态

`unnormal_flag` bit 4: 当槽5,6,8,9任一未穿时置1(服装异常)。影响特定前提判定。

## 5. UI 体现

- **角色信息栏**: 显示大致服装状态(全裸/大致全裸/正常). `cloth_see[6/9]` 控制 bra/panties 的 `可见` 标签
- **H指令过滤**: 指令前提检查 `TARGET_WEAR_PAN`/`TARGET_WEAR_BRA` 等 → 不满足则指令不可见
- **身体部位暴露判定**: `get_exposed_body_parts()` 决定哪些身体部位可被触摸/插入 → 影响指令列表
- **全局UI概览**: 见 [公式手册 §7](./00-公式手册.md#7-ui-上下文总览)
