## 一、美术资源放哪里？完全跟随模组，目录清晰
沿用我们现有的模组目录，所有美术资源都放在模组自己的 `assets/` 文件夹里，按类型分类存放，和数据文件一一对应，引擎本身不带任何固定美术资源。

### 细化后的模组资源目录
```
[模组名]/
├── theme.toml              # 主题变量配置
├── theme.css               # 自定义样式（引用美术资源）
├── characters/
│   └── [角色ID]/
│       └── assets/         # 角色专属素材（头像、立绘、差分）
│           ├── avatar.png
│           ├── sprite.png  # 立绘整图
│           └── expressions/ # 表情差分
├── definitions/
├── maps/
├── quests/
└── assets/                 # 模组公共美术资源（全模组通用）
    ├── ui/                 # UI皮肤资源
    │   ├── panel-bg.png    # 面板背景纹理
    │   ├── button-normal.png # 按钮常态纹理
    │   ├── button-hover.png  # 按钮悬停纹理
    │   ├── border.png      # 边框装饰
    │   └── icons/          # 图标素材（物品、技能、属性图标）
    ├── bg/                 # 场景背景图
    │   ├── huashan.jpg     # 华山场景背景
    │   └── tavern.jpg      # 酒馆场景背景
    ├── map/                # 地图素材
    │   ├── world-map.jpg   # 大地图底图
    │   └── location-icons/ # 地点标记图标
    ├── pixel/              # 像素美术资源（像素风模组用）
    │   └── tiles/
    ├── audio/              # 音效与音乐
    │   ├── bgm/            # 背景音乐
    │   └── sfx/            # 音效（点击、战斗、提示音）
    └── video/              # 可选：过场动画、OP等
```

### 关键规则
1. **专属资源就近放**：单个角色的立绘、头像，就放在角色自己的 `assets/` 里，找素材、替换素材都不用翻遍项目；
2. **公共资源统一放**：UI皮肤、公共图标、全局背景，放在模组根目录的 `assets/` 里，全模组复用；
3. **引擎零资源**：引擎本身不包含任何美术素材，所有视觉内容都来自模组，换模组自动切换全套美术，不会有残留。

## 二、资源怎么用？三种方式，全不用改引擎代码
美术资源的引用分为三类，覆盖所有使用场景，全部在模组层面就能完成，不需要动引擎内核。

### 1. 数据文件里直接引用路径（最常用，零代码）
角色头像、地点背景、物品图标、技能图标这类和数据绑定的资源，直接在 TOML 数据文件里写文件路径即可，引擎自动读取渲染。

示例：
```toml
# 角色 base.toml
name = "令狐冲"
avatar = "characters/linghuchong/assets/avatar.png"
sprite = "characters/linghuchong/assets/sprite.png"
```

```toml
# 地点配置
id = "huashan_tavern"
name = "华山酒馆"
background = "assets/bg/tavern.jpg"
```

```toml
# 物品定义
[金疮药]
name = "金疮药"
icon = "assets/ui/icons/potion.png"
```

- 特点：纯配置，不用写一行样式代码，AI生成数据时直接带上路径就行；
- 自动适配：引擎会自动根据当前模组路径补全资源地址，不用写绝对路径。

### 2. 主题 CSS 里引用（做皮肤质感、UI美化）
面板纹理、按钮皮肤、背景图、边框装饰这类和视觉风格绑定的资源，直接在模组的 `theme.css` 里通过 CSS 引用，和主题变量配合，换主题自动换资源。

示例（武侠古风主题）：
```css
/* 面板加宣纸纹理背景 + 木质边框 */
.game-panel {
  background-image: url('./assets/ui/paper-bg.png');
  background-repeat: repeat;
  border: 3px solid transparent;
  border-image: url('./assets/ui/wood-border.png') 3 stretch;
}

/* 按钮加渐变纹理 + 悬停效果 */
.game-button {
  background-image: url('./assets/ui/btn-normal.png');
  background-size: 100% 100%;
}
.game-button:hover {
  background-image: url('./assets/ui/btn-hover.png');
}

/* 全局场景背景 */
.scene-container {
  background-image: url('./assets/bg/default-bg.jpg');
  background-size: cover;
  background-position: center;
}
```

- 特点：美术效果上限极高，纹理、发光、投影、帧动画都能实现；
- 完全隔离：样式只在当前模组生效，切换模组自动卸载，不会污染其他主题。

### 3. 插件自带资源（玩法插件专属UI）
如果某个玩法插件有自己的专属美术（比如战斗插件的血条素材、卡牌插件的卡面边框），资源直接放在插件自己的目录里，插件自己引用，不污染全局。

```
src/plugins/combat-wuxia/
├── logic/
├── ui/
└── assets/       # 战斗插件专属美术资源
    ├── hp-bar.png
    └── attack-effect.png
```

## 三、能做到什么美术程度？覆盖你要的所有2D游戏效果
纯 Vue + CSS + 图片资源，完全可以做到商业级H5文字/卡牌游戏的美术质感，你提到的像素美术、立绘、场景背景、UI皮肤全部支持，甚至轻量动画也不在话下。

### 1. 像素美术完美支持
针对像素风素材，只需要在主题CSS里加一行配置，就能保证像素锐利不模糊：
```css
/* 全局像素风渲染，不做模糊插值 */
:root {
  image-rendering: pixelated;
  image-rendering: crisp-edges;
}
```
- 支持像素瓦片地图、像素角色、像素UI；
- 可以做像素帧动画（CSS 逐帧动画 + 精灵图），比如角色待机、走路、攻击动画；
- 不需要任何额外引擎，纯CSS就能实现，性能极好。

### 2. 立绘与差分表情
- 支持角色立绘全屏/半屏显示，支持透明PNG；
- 支持表情差分、服装差分，根据剧情/状态自动切换；
- 支持简单的Live2D式呼吸、晃动动画（纯CSS过渡动画实现，不需要额外插件）。

### 3. UI皮肤与沉浸感
- 支持完整皮肤替换：从按钮、面板、边框到滚动条，全部可以换成自定义纹理；
- 支持特效装饰：边角花纹、发光效果、卷轴质感、魔法阵光晕等；
- 支持场景背景：每个地点配独立背景图，进入地点自动切换，沉浸式拉满。

### 4. 音效与视频
- 音效：HTML5原生支持，背景音乐、点击音效、战斗音效都可以配置，在数据里写路径就能播放，支持循环、淡入淡出；
- 视频：支持MP4/WebM格式的过场动画、OP视频，可以在剧情节点里触发播放。

### 5. 轻量动画与特效
- CSS过渡动画：按钮悬停、面板弹出、属性变化，都可以做平滑过渡；
- 帧动画：技能特效、伤害数字、buff图标跳动，用精灵图+CSS动画就能实现；
- 粒子效果：简单的雪花、落叶、魔法光点，可以用轻量JS粒子库实现，按需加载。

> 注：你要的「卡牌、文字冒险、UI驱动的成熟H5游戏美术」，就是这套技术路线的标准应用场景，完全不需要Canvas/3D引擎，纯DOM+CSS+图片就能做到。

## 四、后期新增、维护、替换方便吗？零代码成本
**非常方便，绝大多数情况都不需要改代码，直接替换文件、修改路径就能完成。**

### 1. 替换美术资源：直接覆盖文件
比如想换令狐冲的头像，直接用新图片覆盖掉 `characters/linghuchong/assets/avatar.png`，刷新游戏就生效，不用改任何配置、任何代码。

### 2. 新增美术资源：放文件 + 填路径
比如新增一个物品图标：
1. 把图标文件放到 `assets/ui/icons/` 里；
2. 在物品定义的 TOML 里加一行 `icon = "assets/ui/icons/新物品.png"`；
3. 完成，引擎自动加载显示。

全程不用懂代码，不用动引擎，纯文件操作+配置修改。

### 3. 批量换皮：替换整个assets文件夹
想把整个模组从古风换成魔幻风，只需要：
1. 替换 `assets/` 里的所有图片资源；
2. 微调 `theme.toml` 的颜色变量；
3. 刷新就完成整体换皮，逻辑、数据、剧情完全不用动。

### 4. AI友好度拉满
- 让AI生成主题CSS，只要告诉它「古风武侠风格，用assets里的纹理图」，它就能写出完整的样式代码；
- 让AI批量生成角色、物品数据，自动带上对应的资源路径，格式极其稳定；
- 美术素材和代码完全解耦，AI不用管资源怎么渲染，只管填路径就行。

## 五、几个关键的技术保障（不用你管，但你可以放心）
1. **自动打包与压缩**：Vite 构建时会自动压缩图片、优化资源体积，不会因为资源多导致加载慢；
2. **懒加载**：立绘、背景图、视频等大资源支持按需加载，进入对应场景才加载，不浪费流量；
3. **路径自动处理**：引擎会自动处理模组的资源路径，你只需要写相对路径，不用关心打包后的地址；
4. **缓存优化**：资源更新后自动刷新缓存，不会出现玩家看到旧图的问题。
