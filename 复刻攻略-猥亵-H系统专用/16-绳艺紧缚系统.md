# 绳艺紧缚系统

> 本文档描述绳缚(bondage)的等级、施加、实时效果及影响。

---

## 1. 数据结构

`h_state.bondage: int` — bondage类型ID (0=无捆绑)

### 1.1 紧缚等级

| LV | 名称 | 所需指技(ability[70]) |
|----|------|:---:|
| 0 | 无 | — |
| 1 | 低 | ≥2 |
| 2 | 中 | ≥4 |
| 3 | 高 | ≥6 |

---

## 2. 施加/解除

**面板**: `Bondage_Panel` → 选择级别 → 实行判定(SM类)

```
捆绑: behavior BIND (603)
解除: behavior UNBIND (633)
```

需持有绳子(item[131])。爱情旅馆顶级套房免消耗。

---

## 3. 实时效果

```
捆绑中, 每时间刻度:
  欲情(12) += true_add_time × 3 × ability[33]修正 × (bondage_level × 0.5)
  羞耻(16) += true_add_time × 3 × ability[34]修正 × (bondage_level × 0.5)
  苦痛(17) += true_add_time × 3 × ability[15]修正 × (bondage_level × 0.5)
```

捆绑等级越高, 欲情/羞耻/苦痛积累越快。

---

## 4. 影响

- 被捆绑NPC在H中不可反抗
- 束缚影响NPC AI行动
- 部分SM道具(眼罩/口球)可配合使用

---

## 5. UI 体现

- **H指令面板**: 紧缚作为 SEX→SM 子类出现, 或单独调用 Bondage_Panel
- **角色信息**: 紧缚状态在角色脏污/身体状态面板中显示
- **绳子需求**: 需持有 item[131]; 爱情旅馆顶级套房免消耗
- **全局UI概览**: 见 [公式手册 §7](./00-公式手册.md#7-ui-上下文总览)
