
## 3. 催眠深度增长公式

```
final = round(base * adjust, 1)
base = 1
adjust = 基础系数 × 调香加成 × 无觉刻印(ability[19]) × random(0.5~1.5)

基础系数:
  平然(331): 2
  空气(333)/深度(332): 4
  完全(334): 6

调香加成: aromatherapy==6 → +5
无觉刻印: get_ability_adjust(ability[19]) (乘法系数)
```

## 5. 催眠对H同意门的影响

### 5.1 实行判定修正 (`instuct_judege.py:318-356`)

```
若目标 unconscious_h ∈ {4,5,6,7} 且 judge_data_type == "S":
  - 完全被催眠(73) → judge += 9999 (直接通过)
  - 性骚扰/亲吻: 需被浅层催眠(71) + 深度≥50%，不足部分理智折算
  - 性行为(S类): 需中级催眠(332) + 被深层催眠(72) + 深度≥100%

理智→实行值换算:
  深层催眠: 1理智 = 20实行值
  其他: 1理智 = 10实行值
```

### 5.2 催眠替代信赖度

```
hypnosis_replace_trust_flag = True 时:
  若 hypnosis_degree >= judge_value / 2 → 通过
```

## 6. 子状态效果

### 6.1 体感敏感度提升

- 理智消耗: 10(开启)/0(关闭)
- 快感系数: +2
- 欲情(12)加成: +2

### 6.2 强制排卵

- 理智消耗: 10(开启)
- 强制 reproduction_period = 5
- 受孕率 ×5 (一次性消耗)

### 6.3 木头人

- 理智消耗: 10(切换)
- NPC锁定WAIT行为
- 例外: 睡眠行为中不锁; 6异常(深度无意识)中不锁

### 6.4 逆推

- 理智消耗: 10(切换)
- 自动设置 `npc_active_h = True` + 触发H指令

### 6.5 角色扮演

- 家庭: 妻子/姐姐/妹妹/女儿/妈妈
- 职业: 校园/护士/偶像/女仆/巫女/警察/白领
- 关系: 师生/同学/非家庭
- 人外: 宠物猫/宠物狗/魅魔
- 场景: 电车痴汉/户外当众/公厕/俘虏拷问/战败魔法少女等
- 非特殊类各类选一个可同时起效; 特殊类与其他互斥

### 6.6 苦痛快感化

- 理智消耗: 10(切换)
- 状态17(苦痛)结算 → 按状态23(心理快感)结算
- 阻止苦痛刻印触发

---

## 7. 空气催眠特殊机制

- 场景门自动锁上
- 位置绑定: 目标离开绑定位置 → 自动解除
- NPC不可在空气催眠角色前进行交互
