# 香薰疗愈系统

> 香薰是每日可用的buff系统(类似春药/精油/debuff), 8种配方对目标施加持续1天的数值修正。

---

## 1. 八种香薰效果

`sp_flag.aromatherapy: int` (0-8), 每天重置为0:

| ID | 名称 | 效果 |
|----|------|------|
| 0 | 无 | — |
| 1 | 回复 | HP/MP回满 |
| 2 | 习得 | state[9](习得) 获得速度 +1.0 |
| 3 | 反感 | 苦痛/恐怖/抑郁/反感(17/18/19/20) 积累速度 -0.5 |
| 4 | 快感 | 全快感 +1.0; state[12](欲情) +1.0 |
| 5 | 好感 | 好感/信赖获得 ×1.5 (+50%) |
| 6 | 催眠 | 催眠增长系数 +5 |
| 7 | 射精 | 射精量 ×2 |
| 8 | 疲劳 | 疲劳增长速度 ×0.8 |

---

## 2. 使用流程

1. **入口**: 主界面→指令→香薰疗愈 (AROMATHERAPY 面板)
2. **选择目标**: 当前交互目标
3. **条件**: 剩余今日次数>0 + 目标今日未使用过香薰
4. **每日次数**: 疗养庭院(设施16)等级决定:
   - LV≤3: 1次/天
   - LV4: 2次/天
   - LV5+: 3次/天
5. **配方解锁**: 需要 `ability[47](农业技能) >= 难度 × 2`
6. **消耗**: 香料(item[16]) + 浓缩香精(item[41]) / 高级香水(item[43])
7. **执行**: 60分钟行为, 消耗资源, 次数-1
8. **持续**: 当天有效, 午夜重置为0
