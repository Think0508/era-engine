## 1. 数据结构

### 1.1 PREGNANCY 类

`game_type.py` line 331+:
| 字段 | 类型 | 说明 |
|------|------|------|
| `fertilization_time` | `int` | 受精日期(距游戏开始的累计天数) |
| `past_day` | `int` | 当前阶段经过天数 |
| `milk` | `int` | 当前奶水量ml |
| `milk_max` | `int` | 最大奶水量ml |
| `state` | `int` | 当前阶段状态码 |

### 1.2 阶段状态 (pregnancy.state)

| 值 | 阶段 | 说明 |
|----|------|------|
| 0 | 未妊娠 | 默认 |
| 1 | 受精 | 射精后判定受孕 |
| 2 | 妊娠 | 受孕确认, 孕期推进 |
| 3 | 临盆 | 即将生产 |
| 4 | 生产 | 分娩当天 |
| 5 | 产后 | 生产后 |
| 6 | 育儿 | 育儿期 |
| 7 | 完成 | 育儿结束 |

### 1.3 女儿成长阶段

| 阶段 | `past_day` 阈值 |
|------|----------------|
| 婴儿 | 0-269天 |
| 幼女 | 270-449天 |
| 萝莉 | 450天+ |

## 2. 受孕判定

### 2.1 触发条件

射精在V/体内（阴道/子宫）时，调用 `pregnancy.check_fertilization_rate()`。

### 2.2 基础受孕率

- 来源于 `data/csv/` 中相关配置（受角色素质、生理周期等影响）
- 生理周期 `reproduction_period`: 0→1→...→5→6→0 循环，影响受孕率倍率

### 2.3 受孕率修正

| 修正源 | 效果 | 说明 |
|--------|------|------|
| 排卵促进药 (body_item[10]) | ×5 (上限100%) | 使用后消耗 |
| 事前避孕药 (body_item[11]) | 受孕率=0 | 绝对防止, 30天有效 |
| 事后避孕药 (body_item[12]) | 受孕率=0 | 一次性, 使用后消耗 |
| 素质(talent) | 加减修正 | 各类生殖相关素质 |
| 体质/能力 | 修正 | — |

### 2.4 判定结果

```
if random(0, 100) < 受孕率:
    pregnancy.state = 1  # 受精
    pregnancy.fertilization_time = 当前游戏累计天数
    pregnancy.past_day = 0
```

## 3. 孕期推进

每次睡眠触发 `pregnancy.check_all_pregnancy()`:

### 3.1 受精 → 妊娠

```
条件: past_day >= 90天 (从受精日起)
  state → 2 (妊娠)
```

### 3.2 妊娠 → 临盆

```
条件: past_day >= 260天 (从受精日起)
  state → 3 (临盆)
```

### 3.3 临盆 → 生产

```
每过一天概率 = past_day × 20%
  past_day 越大, 分娩概率越高
  state → 4 (生产)
```

### 3.4 生产 → 产后

```
条件: past_day >= 2天
  state → 5 (产后)
  生成女儿Character
```

### 3.5 产后 → 育儿

```
条件: past_day >= 2天
  state → 6 (育儿)
```

### 3.6 育儿 → 完成

```
条件: past_day >= 90天
  state → 7 (完成)
```

### 3.7 女儿成长

```
past_day >= 270 → 婴儿 → 幼女
past_day >= 450 → 幼女 → 萝莉
```

## 4. 泌乳系统

### 4.1 奶水积累

```
泌乳素质 (talent[27]) 存在时:
  milk_change = int(true_add_time × 2 / 3)  (每分钟约0.67ml)
  milk = min(milk + milk_change × random(0.8, 1.2), milk_max)

榨乳机 (body_item[4]) 在H中:
  每次循环: milk -= min(milk, 5 × behavior.duration)
  存入: rhodes_island.milk_in_fridge[character_id]
```

### 4.2 奶水消耗

- 榨乳机自动收集
- 状态变化消耗

## 5. 素质变化

妊娠/生产/育儿过程中获得/失去相关素质(talent)标记：
- 受精中标记
- 妊娠中标记
- 育儿中标记
- 各项对好感/能力等有修正 (见 [公式手册]#公式1)
