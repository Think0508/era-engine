### 2.2 激活前提

```
PRIMARY_TIME_STOP (talent[316])
TIME_STOP_OFF
SANITY_POINT_G_0 (理智>0)
TIRED_LE_84 (疲劳≤84)
```

### 2.3 理智消耗

```
时停中: 每真实分钟消耗 2 点理智
min_cost = 1/次, scale = 2/min
若理智归零: 自动中断所有源石技艺(含时停)
```

## 3. 行为循环中的时停

### 3.1 核心逻辑 (`character_behavior.py:58-62`)

```
1. 玩家执行行为 → 行为结算
2. 若 time_stop_mode == True:
   - achievement.time_stop_duration += 玩家行为时长
   - 游戏时间 回滚 玩家行为时长 (时间不前进)
   - break (跳过所有NPC阶段)
3. 若 time_stop_mode == False:
   - 正常NPC阶段
```

### 3.2 移动限制

- 窄域时停: 不可移动
- 广域时停(317): 可移动 (TIME_STOP_JUDGE_FOR_MOVE 前提通过)

### 3.3 时停开启/关闭时

**开启时**: 全场角色 `sp_flag.unconscious_h = 3` (时停状态), `unnormal_flag` bit 6 设置

**关闭时**: 
- 全场角色 `unconscious_h = 0` (还原)
- 触发 `TIME_STOP_ORGASM_RELEASE` (效果527): 所有角色结算累积的时停绝顶
- 结算无意识期间的 semen/cloth 变化
- 绝顶≥3次触发超强绝顶 (需敏感度ability≥6, 否则降为强度绝顶)

---

## 4. H内时停效果

### 4.1 绝顶累积

```
H中绝顶 → 时停期间不处理 → 累积到 time_stop_orgasm_count[部位ID]
```

### 4.2 时停解放

```
时停关闭 → 所有累积绝顶 一次性爆发结算
若累积≥3次 → 超强绝顶
time_stop_release = True (触发送话权重加算)
```

### 4.3 HP/MP不消耗

时停中的HP/MP结算被跳过 (`common_default.py:51-53`)

### 4.4 实行判定

时停中目标处于 `unconscious_h=3` → 实行判定 +9999(命中保证)

## 5. 搬运系统(广域时停)

- CARRY_TARGET: 搬运目标跟随玩家
- STOP_CARRY_TARGET: 放下
- TARGET_FREE_IN_TIME_STOP: 允许目标自由活动 (理智50消耗, 未实装)
- TARGET_STOP_IN_TIME_STOP: 再次冻结目标 (未实装)
