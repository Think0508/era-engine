> 引用的核心公式见 [公式手册](./00-公式手册.md)。本文档描述 sleep/unconscious H 的启动、无意识等级、唤醒机制、经验系统。

## 1. unconscious_h 等级

`sp_flag.unconscious_h: int` — 0~7:

| 值 | 名称 | 触发方式 |
|----|------|---------|
| 0 | 无 | 正常 |
| 1 | 睡眠 | 睡眠猥亵指令 / 自然睡眠 |
| 2 | 醉酒 | 醉酒状态 |
| 3 | 时停 | 时停激活 |
| 4 | 平然催眠 | 催眠类型1 |
| 5 | 空气催眠 | 催眠类型2 |
| 6 | 体控催眠 | 催眠类型3 |
| 7 | 心控催眠 | 催眠类型4 |

## 3. 唤醒机制

### 3.1 睡眠等级

| LV | 名称 | sleep_point |
|----|------|:----------:|
| 0 | 半梦半醒 | 0-30 |
| 1 | 浅睡 | 31-60 |
| 2 | 熟睡 | 61-80 |
| 3 | 完全深眠 | 81-100 |

### 3.2 唤醒判定

```
weak_rate = (60 - sleep_point) + (max(30 - sleep_point, 0))
# 半梦半醒(20): weak_rate = 40 + 10 = 50 → 50%
# 浅睡(45): weak_rate = 15 + 0 = 15 → 15%

if weak_rate >= random(1, 100):
    唤醒 → sleep_h_awake = True → 玩家有5分钟反应
```

### 3.3 安眠药效果

安眠药(body_item[9]) → sleep_level 强制=2(熟睡) → 完全阻止唤醒

---

## 4. 唤醒后处理

1. `sleep_h_awake = True`
2. 玩家5分钟反应窗口
3. 结算无意识期间的 semen/cloth → `settle_unconscious_semen_and_cloth()`
4. 选择: 继续H(装睡模式) 或 结束H

---

## 5. 无意识经验系统

### 5.1 经验映射

任意经验获得时，若目标处于无意识状態(unconscious_h≥1或时停解放):
- Type 1(部位快感) → 无意识部位经验 (exp 70-77, 159-161)
- Type 2(绝顶) → 无意识绝顶经验 (exp 78)
- Type 3(性交) → 无意识性交经验 (exp 79) + 状态特化经验

### 5.2 状态特化经验

| 无意识状态 | 玩家获得 | 目标获得 |
|-----------|---------|---------|
| 睡眠(1) | 睡姦经验(120) | 被睡姦经验(121) |
| 时停(3) | 时姦经验(124) | 被时姦经验(125) |
| 催眠(4-7) | 催眠姦经验(126) | 被催眠姦经验(127) |

### 5.3 心理经验限制

`NORMAL_6 == False` (深度无意识) 时 → 心理经验(Type 7) 不获得

---

## 6. 异常标识 (unnormal_flag) 位掩码

| Bit | 位值 | 说明 | 设置条件 |
|-----|------|------|---------|
| 5 | 0x10 | 意识模糊/弱交互 | 半梦半醒 + 睡眠行为/睡眠无意识; 平然催眠 |
| 6 | 0x20 | 完全意识不清醒/无交互 | 浅睡+ + 睡眠; 空气催眠; 时停 |
