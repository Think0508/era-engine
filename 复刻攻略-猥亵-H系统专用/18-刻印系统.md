# 刻印系统

> 刻印是永久性的特殊能力(ability type 2, IDs 13-19)，在H中积累、睡眠中升级，影响实行判定、好感获得、状态积累速率。

---

## 1. 七种刻印总览

| ID | 名称 | 最大等级 | 可否降级 | 核心影响 |
|----|------|:---:|:---:|------|
| 13 | 快乐刻印 | 3 | 不可 | 实行值+50/lv, 好感+0.2/lv |
| 14 | 屈服刻印 | 3 | 不可 | 实行值+50/lv, 好感+0.2/lv, 隶属系前置 |
| 15 | 苦痛刻印 | 3 | 可(宝珠) | 实行值+10/lv, 好感-0.3/lv |
| 16 | 时姦刻印 | 3 | N/A | **未实装** |
| 17 | 恐怖刻印 | 3 | 可(宝珠) | 实行值-50/lv, 好感-0.3/lv |
| 18 | 反发刻印 | 3 | 可(宝珠/道具) | 实行值-100/lv, 好感-1.0/lv |
| 19 | 无觉刻印 | **6** | 不可 | 实行值+25/lv |

## 2. 积累公式（单次H中）

### 2.1 快乐刻印 (13): 绝顶计数

```
single_happy = sum(全快感部位 orgasm_count[部位][0])  # 本次指令绝顶
all_happy = sum(全快感部位 orgasm_count[部位][1])     # 整个H会话绝顶
```

| LV | single ≥ | 或 all ≥ |
|----|:------:|:------:|
| 1 | 2 | 5 |
| 2 | 8 | 20 |
| 3 | 16 | 50 |

### 2.2 屈服刻印 (14): 状态累计

```
yield_count = status_data[15](屈服) + status_data[10](恭顺) + status_data[16](羞耻) × 0.2
```

| LV | 阈值 |
|----|:----:|
| 1 | 30,000 |
| 2 | 50,000 |
| 3 | 100,000 |

### 2.3 苦痛刻印 (15): 苦痛累计 + 爆发加成

```
pain_count = 累计status_data[17](苦痛) + change_data.status_data[17] × 5  (单指令爆发)
```

条件: 非深度无意识 + 非心控-苦痛快感化

| LV | 阈值 |
|----|:----:|
| 1 | 20,000 |
| 2 | 40,000 |
| 3 | 80,000 |

### 2.4 恐怖刻印 (17): 恐怖+苦痛加权

```
terror_count = status_data[18](恐怖) + status_data[17](苦痛) × 0.2
             + change_data.status_data[18] × 5  (单指令爆发)
             + change_data.status_data[17]
```

| LV | 阈值 |
|----|:----:|
| 1 | 20,000 |
| 2 | 40,000 |
| 3 | 80,000 |

### 2.5 反发刻印 (18): 四维负面

```
hate_count = status_data[17](苦痛)+status_data[18](恐怖)+status_data[19](抑郁)+status_data[20](反感)
           + change_data.status_data[20] × 5  (单指令爆发)
```

条件: 非深度无意识

| LV | 阈值 |
|----|:----:|
| 1 | 10,000 |

| 3 | 80,000 |

### 2.6 无觉刻印 (19): 无意识绝顶

```
LV1-3: 同快乐刻印的绝顶计数 (single/all, 需无意识状态)
LV4-6: 体验[78](无意识绝顶经验) ≥ 100/200/500
```

## 3. 升级触发

- **触发点**: `second_behavior.py` → `mark_effect()` — H行为结算后
- **逻辑**: 若 `count >= 阈值` 且当前等级 < 目标等级 → 升级
- 升级时连动提升关联能力:
  - 快乐刻印LV1/2/3 → 欲望(33)至少升到 LV1/3/5
  - 屈服刻印LV1/2/3 → 顺从(31)至少升到 LV1/3/5
  - 苦痛刻印LV1/2/3 → 受虐(36)至少升到 LV1/3/5
  - 无觉刻印LV4/5/6 → 欲望(33)至少升到 LV6/7/8

## 4. 刻印对系统的全局影响

### 4.1 实行值 (instuct_judege.py)

```
judge_mark = ability[13]×50 + ability[14]×50 + ability[15]×10 + ability[19]×25
judge_mark -= max(ability[17]-ability[16], 0)×50 + ability[18]×100
```

反发刻印LV3 = -300 实行值, 几乎让所有指令失败。

### 4.2 好感度 (公式手册 公式#1)

| 刻印 | 修正/lv |
|------|:-----:|
| 快乐(13) | +20% |
| 屈服(14) | +20% |
| 苦痛(15) | -30% |
| 恐怖(17) | -30% |
| 反发(18) | **-100%** |

### 4.3 状态积累速度 (common_default.py)

刻印等级≥1后, 使用 `get_mark_debuff_adjust()` 替代普通能力修正:

| 刻印LV | 倍率 |
|:-----:|:---:|
| 0 | 1.0x |
| 1 | 1.5x |
| 2 | 3.0x |
| 3 | 5.0x |

影响状态: 快乐(13)/屈服(15)/苦痛(17)/恐怖(18)/反感(20) — 刻印越高, 这些状态积累越快(正反馈螺旋)。

### 4.4 宝珠转换 (睡眠时)

负面状态(17/18/19)转换率降低:
```
自身珠: add_juel // 4  (25%)
反感珠: add_juel // 2  (50%)
```
正面状态: 100% 转换

睡眠时反感珠抵消正面珠: 1反感珠消灭 2 好意/恭顺/欲情/快乐/屈服珠。

## 5. 降级机制

仅苦痛/恐怖/反发刻印可降级(快乐/屈服/无觉不可降)。

### 5.1 宝珠降级 (能力面板手动)

**苦痛刻印 (15)**:
| 降级 | 需宝珠总价值 | 消耗 |
|------|:--------:|------|
| 1→0 | 10,000 | 全快感珠 + 快乐珠(13) |
| 2→1 | 30,000 | 同上 |
| 3→2 | 50,000 | 同上 |

**恐怖刻印 (17)**:
| 降级 | 需宝珠总价值 | 消耗 |
|------|:--------:|------|
| 1→0 | 10,000 | 好意珠(11)×2 + 欲情珠(12)×2 + 羞耻珠(16) |
| 2→1 | 30,000 | 同上 |
| 3→2 | 50,000 | 同上 |

**反发刻印 (18)**:
| 降级 | 需宝珠总价值 | 消耗 |
|------|:--------:|------|
| 1→0 | 20,000 | 恭顺珠(10)×2 + 屈服珠(15)×3 + 苦痛珠(17) |
| 2→1 | 40,000 | 同上 |
| 3→2 | 60,000 | 同上 |

全快感珠 = 所有 type==0 的快感状态对应宝珠 (皮肤/胸部/阴蒂/阴茎/阴道/肛肠/尿道/子宫/口喉/兽部/心理, 共11种)。

### 5.2 道具降级

- 道歉礼物 (item[171]): 消耗1个, 反发刻印 -1级
