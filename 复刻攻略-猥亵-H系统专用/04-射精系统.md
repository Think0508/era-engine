## 2. 射精欲积累

### 2.1 H内积累

每次P部位(Penis=3)快感产生时:
```
eja_point += 100 + int(eja_point × 0.4)
```
从 Second_effect.py `ADD_SMALL_P_FEEL` 效果。

### 2.2 非H衰减

```python
if not is_h and (now - last_eja_time) > 30min:
    eja_point = max(eja_point - int(true_add_time × 10), 0)
    # 每分钟减少10
```

### 2.3 显示等级

```
0          = 不显示
1~300      = 低
301~600    = 中
601~900    = 高
901~1000   = 极 (即将射精)
```

## 3. 射精触发

### 3.1 触发条件

```python
if eja_point >= eja_point_max:  # eja_point >= 1000
    触发 ejaculation_panel
```

### 3.2 忍耐判定

```python
now_lv = ability[30]             # 忍耐能力等级
now_count = endure_not_shot_count # 当前H中已忍耐次数

if now_count <= now_lv:
    now_rate = 100               # 必定成功
else:
    over_count = now_count - now_lv
    down_rate = 50 - now_lv × 5  # 每次下降率
    now_rate = max(0, 100 - over_count × down_rate)
```

**忍耐成功**:
- `endure_not_shot_count += 1`
- `eja_point = 0`
- 不消耗精液

**忍耐失败或主动射精**:
- 根据 `endure_not_shot_count` 确定强度:
  - 0次 → `p_orgasm_small` (普通射精)
  - 1-3次 → `p_orgasm_normal` (强射精)
  - 4+次 → `p_orgasm_strong` (超强射精)

## 4. 射精量计算公式

```
semen_count_raw = base_semen × random(0.8, 1.2)
```

### 4.1 基础射精量 (ml)

| 强度 | base_semen |
|------|-----------|
| p_orgasm_small | 10 |
| p_orgasm_normal | 20 |
| p_orgasm_strong | 50 |

### 4.2 耐力倍率 (normal/strong only)

```
semen_count = semen_count_raw × (endure_not_shot_count + 1)
```

### 4.3 叠加倍率 (各×2, 乘算)

| 条件 | 倍率 | 消耗标记 |
|------|------|---------|
| 醒来第一发 (day_first_shoot_semen) | ×2 | 使用后设为False |
| 精力剂 (used_semen_energy_agent) | ×2 | 使用后设为False |
| 香薰疗愈-射精 (aromatherapy_flag_7) | ×2 | — |
| 积攒精液 (tem_extra_semen_point >= semen_point_max) | ×2 | — |
| 浓厚精液 (talent[33]) | ×2 | — |
| 交互对象榨精能力 (ability[77]) | ×adjust | — |

### 4.4 最终上限

```
semen_count = min(semen_count, semen_point + tem_extra_semen_point)
```

## 5. 精液扣除

```
优先扣临时额外精液:
  if tem_extra_semen_point > semen_count:
    tem_extra_semen_point -= semen_count
  else:
    semen_count -= tem_extra_semen_point
    tem_extra_semen_point = 0
    semen_point -= semen_count

semen_point = max(0, semen_point)
```

## 6. 精液恢复

### 6.1 自然恢复

```
每20分钟真实时间恢复1ml, 上限semen_point_max
```

### 6.2 临时额外精液（睡眠转化）

```python
# 睡眠 ≥6小时触发
tem_extra_semen_point += int(semen_point / 2)  # 当前精液50%转化
tem_extra_semen_point = min(该值, semen_point_max × 4)  # 上限400ml

# 若达到上限:
talent[33] = 1  # 获得浓厚精液(存续1天)
```

## 7. 射精位置

### 7.1 位置选择

- **系统设定[3] = False**: 自动射在阴茎当前插入位置
- **系统设定[3] = True**: 手动选择
  - 身体部位 (暴露中或阴茎插入中)
  - 服装部位 (穿着中)

### 7.2 精液注入效果

射入身体部位后:
- `body_semen[部位ID][1]` += 射精量
- 触发精液流动计算
- 如果是V/体内: 触发受孕判定 (见 [妊娠系统].md)
- 如果是A(8): 触发精液灌肠判定

## 8. 精液吸收

`realtime_settle.py` line 224: 仅对体内精液生效 (A部位+食道):

```python
absorb_ml = max(true_add_time // 5, 当前精液量 × 0.01)  # 每5min吸1ml 或 1%
absorb_ml = min(absorb_ml, 当前精液量)

body_semen[部位][1] -= absorb_ml
absorbed_total_semen += absorb_ml
hunger_point = max(hunger_point - absorb_ml, 0)  # 吸收减少饥饿

# 残余 < 3ml → 清零
if body_semen[部位][1] < 3:
    body_semen[部位][1] = 0
```

## 11. 避孕套模式

当 `body_item[13][1] == True`:
- 射精量捕获在避孕套: `condom_count[0] += 1, condom_count[1] += semen`
