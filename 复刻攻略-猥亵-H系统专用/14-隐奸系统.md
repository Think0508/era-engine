# 隐奸系统

> 本文档描述隐奸(hidden sex)的等级、启动、隐匿性、被发现度/概率、结算效果。

---

## 1. hidden_sex_mode 等级

`sp_flag.hidden_sex_mode: int` — 0~4:

| 值 | 名称 | 发现倍率 |
|----|------|:-------:|
| 0 | 否 | — |
| 1 | 双不隐(两人都暴露) | 2.0x |
| 2 | 女隐(女隐藏) | 1.0x |
| 3 | 男隐(男隐藏) | 1.0x |
| 4 | 双隐(两人都隐藏) | 0.5x |

---

## 2. 启动

**指令**: `ASK_HIDDEN_SEX` (5053)

**模式2,3,4**: 需要场景仅2人 或 其他所有人无意识/睡眠

**实行判定**: 隐奸类, 场景惩罚 = 60 + 60×other_count (比普通H更高)

NPC AI直接**看不到**隐藏角色:

| 角色隐藏条件 | 对其他NPC不可见 | 对玩家可见 |
|-------------|:---:|:---:|
| 玩家 mode 3(男隐) | ✓ | — |
| 玩家 mode 4(双隐) | ✓ | — |
| NPC mode 2(女隐) | ✓ | ✓ |
| NPC mode 4(双隐) | ✓ | ✓ |

玩家隐藏时(mode 3/4): 仅可对也在隐奸模式中的目标执行指令

## 4. 被发现度系统

### 4.1 积累公式

```
每次H行为:
  delta = 行为时长 × 强度 × 发现倍率 / 隐蔽能力(ability[90]) × 人数修正
  强度: 基础1 < 侍奉2 < 插入3 < 道具4

每次等待:
  delta = 行为时长 × (-2 / 发现倍率) × 隐蔽能力
```

### 4.2 发现度等级

| LV | 名称 | 阈值 |
|----|------|:--:|
| 0 | 完全隐蔽 | ≤30 |
| 1 | 隐蔽 | ≤60 |
| 2 | 引人注意 | ≤80 |
| 3 | 随时暴露 | ≤95 |

### 4.3 被发现判定

```
若发现度LV ≥ 2 (值 > 60):
  发现概率 = (当前值 - 60) × 3%
  例: 值=80 → 60%, 值=100 → 100%
```

### 4.4 绝顶暴露

任何绝顶(小/普/强/超) → 触发立即发现度+行为时长×绝顶强度修正

## 5. 结算效果

### 5.1 实时羞耻/快感

```
羞耻(16): 5x时间倍率 × (4 - hidden_sex_mode) 修正 × others修正
心理快感(23): 同上
mode越低保数越高(mode1=+3, mode4=+0)
```

### 5.2 经验

```
每次行为: experience[35](隐奸经验) +1
```
