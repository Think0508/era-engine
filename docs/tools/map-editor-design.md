# 地图编辑器工具设计

> 独立于游戏的开发工具，用于可视化编辑地图的拓扑关系、邻接表、视觉布局。
> 技术栈：Tauri + Vue 3 + Vue Flow
> 项目位置：`tools/map-editor/`

---

## 概述

游戏的地图由三层数据组成，工具全部支持编辑：

| 层 | 数据 | 导出格式 | 对应工具模式 |
|----|------|---------|------------|
| 地点 | 地点元数据（id/name/type/parent/tags/visible） | `locations/*.toml` | 模式 A 默认 |
| 邻接 | 地点间通路（from/to/time_cost/condition） | `graph/*.toml` | 模式 A 边编辑 |
| 视觉 | 手绘底图 + 可点击区域坐标 | `layout/*.json` | 模式 B 固定坐标 |

---

## 模式 A：拓扑图编辑（MVP）

### 概念

节点 = 地点，边 = 通路。支持多级层次（无限深度），可折叠/展开。

### 节点

一个节点包含以下字段，在工具中都可以编辑：

| 字段 | 含义 | 编辑方式 |
|------|------|---------|
| `id` | 唯一标识（自动生成如 `huashan_inn`，也可手动改） | 右键菜单 → 修改 ID |
| `name` | 显示名 | 选中节点后直接输入文字改名 |
| `type` | 类型（region/sect_hq/city/inn/landmark/...） | 侧栏下拉/输入 |
| `parent` | 父节点 ID | Tab 创建子节点时自动设置 |
| `tags` | 标签数组 | Tag 池输入后拖到节点，或选中节点后在侧栏输入 |
| `visible` | 是否在游戏中可选（`false` = 纯区域容器，半透明） | 右键切换 |

### 节点操作

| 操作 | 方式 | 效果 |
|------|------|------|
| 创建节点 | 双击空白处 | 创建一个根节点（`parent=""`） |
| 创建子节点 | 选中节点后按 Tab | 创建子节点，自动连线 parent→child，并补上反向 child→parent 边 |
| 选择节点 | 单击 | 侧栏显示该节点的属性 |
| 拖动节点 | 按住拖拽 | 自由改变画布上的显示位置（不改变 `parent` 关系） |
| 重命名 | 选中后直接输入文字 | 修改 `name` 字段，不改 `id` |
| 修改 ID | 右键菜单 → 修改 ID | 弹输入框，改 `id`（谨慎：影响引用） |
| 切换可见性 | 右键菜单 → 切换显隐 | `visible` 在 true/false 间切换，节点变为半透明/恢复 |
| 删除节点 | 右键菜单 → 删除 | 同时删除相连的所有边 |
| 创建子地图 | 右键菜单 → 创建子地图 | 新开一个画布，该节点作为父节点（详见后文） |

### 边操作

边 = 两个地点之间的通路。边的存在表示"可以从 A 到 B"。

| 操作 | 方式 | 效果 |
|------|------|------|
| 创建边 | 拖拽节点 A 到节点 B（靠近一段距离后吸附） | 生成双向边 |
| 修改耗时 | 单击边 → 弹出数字输入框 | 修改 `time_cost`，回车确认 |
| 切换方向 | 双击边 | 在双向 ↔ 单向 A→B ↔ 单向 B→A 之间循环切换 |
| 添加条件 | 侧栏选中边 → 输入条件表达式 | 写入 `condition` 字段 |
| 删除边 | 右键边 → 删除 | 移除该邻接关系 |

边的可视化样式：

- 双向：两端箭头 `←→`
- 单向 A→B：箭头 `→`
- 条件边：虚线 + 图标 `⚡`
- parent/child 自动边：灰色细线（区别于手动创建的边）

### 层级与折叠

节点左侧显示层级数字标 `1` `2` `3`…，表示第几层。

已展开的节点左侧有 `▼` 图标，点击折叠该层。折叠后子孙节点隐藏，只保留自己和一个指示器"+N 个子节点"。

缩放时，可设置各层级节点的显示阈值：

- 全局缩放 100%+：显示所有层级
- 缩放 50%~100%：隐藏 4 级以下
- 缩放 < 50%：只显示 1~2 级

### Tag 系统

Tag 用于给节点分类和标记，方便后续游戏功能的过滤/条件/渲染分组。

| 操作 | 方式 |
|------|------|
| 创建 Tag | 在 Tag 池输入框输入后回车 |
| 删除 Tag | 单击 Tag 旁的 X |
| 赋予 Tag | 拖拽 Tag 到节点上，或选中节点后在侧栏 Tag 输入框回车 |
| 移除 Tag | 侧栏中节点属性里点 Tag 的 X |
| Tag 着色 | 每个 Tag 可设颜色，节点带上该 tag 后边框自动变色 |

工具默认不带任何 Tag，由 mod 作者自定义。

### 子地图

选中一个节点后，右键 → "创建子地图"，工具开启新画布：

- 新画布的父节点 = 该节点
- 画布标题栏显示面包屑：`中原 → 嵩山 → [子地图]`
- 子地图内所有操作与主地图完全相同
- 不同的地图之间拓扑关系相互独立（不能跨图画边）
- 切换地图通过面包屑或画布标签页

导出时，子地图导出为对应区域文件：

```
主地图（中原） → export/maps/locations/中原.toml + graph/中原.toml
子地图（嵩山） → export/maps/locations/嵩山.toml + graph/嵩山.toml
```

### 导入

| 导入来源 | 操作 |
|---------|------|
| 现有游戏 Mod | 选择 mod 目录 → 工具自动解析 `maps/locations/*.toml` 和 `maps/graph/*.toml` |
| 项目文件 | 打开 `.mapedit` 文件恢复完整编辑状态（含画布布局） |

导入 locations 时自动重建节点位置（树状自动布局，可后续手工拖动调整）。

### 导出

| 导出内容 | 格式 | 目标 |
|---------|------|------|
| 地点元数据 | `maps/locations/{区域}.toml`（每地图一个文件） | 游戏加载 |
| 邻接关系 | `maps/graph/{区域}.toml`（每地图一个文件） | 游戏加载 |
| 工具项目 | `{项目名}.mapedit`（JSON，含布局记忆） | 工具自身读取 |

导出的 TOML 格式：

```toml
# export/maps/locations/中原.toml
[[locations]]
id = "huashan"
type = "sect_hq"
name = "华山派"
parent = "zhongyuan"
tags = ["sword_sect", "martial"]
visible = true

[[locations]]
id = "huashan_inn"
type = "inn"
name = "华山客栈"
parent = "huashan"
tags = ["rest"]

# export/maps/graph/中原.toml
[[edges]]
from = "大雄宝殿"
to = "藏经阁"
time_cost = 3

[[edges]]
from = "华山_思过崖"
to = "终南山_古墓"
time_cost = 60
condition = "player.talents.轻功绝顶 == 1"
```

## 模式 B：固定坐标视觉地图（Phase 3）

在模式 A 完成拓扑图后，点"切换到固定坐标模式"开关进入。此时：

### 背板

画布从纯白切换为**支持图片背景**。操作：

1. 拖入一张图片（或点击"选择背景图"上传 PNG/JPG）
2. 图片平铺到画布上，支持缩放/平移（和模式 A 一样）
3. 一个地图只能有一张背景图

### 节点固定

模式 A 中创建的节点此时可以拖动到背景图的特定位置：

- 拖动节点时，背景图上显示对齐参考线（帮助对齐其他节点）
- 节点的位置使用**比例坐标**（0~1, 0~1）存储，不绑定像素，适配任何分辨率
- 节点放下后，**画布上拖动节点不再改变拓扑数据**，只改变视觉坐标

### 点击区域

游戏里玩家点击地图跳转到对应地点，需要知道"点哪片区域是选中这个节点"。

添加点击区域的方式：

1. 选中节点
2. 在节点上拖拽出一个矩形框（从节点中心点向外拉）
3. 矩形框覆盖的范围就是游戏里的可点击区域
4. 一个节点可以有多个点击区域（比如一个大门按钮 + 一个城墙范围都指向同一个地点）
5. 拖拽矩形框角落/边缘可以改变其大小和形状

点击区域在画布上以半透明色块显示，选中时高亮。

### 路径绘制

点与点之间的边可以在背景图上画曲线：

1. 双击一条边 → 进入"画路径"模式
2. 在背景图上单击添加贝塞尔路径控制点
3. 路径渲染为曲线，箭头在终点
4. 完成后按 Esc 退出路径编辑
5. 不画路径的边在视觉模式下默认为两点间直线（虚线）

### 面向不同层级的视觉地图

主地图和子地图都可以有各自的视觉地图：

```
中原.png（主地图）→ 标出嵩山、华山等大山位置
  嵩山.png（子地图）→ 标出少林寺、嵩山派等具体位置
    少林寺.png（子子地图）→ 标出大雄宝殿、藏经阁等
```

面板上通过面包屑切换：`中原 → 嵩山 → 少林寺`

### 导出视觉数据

```json
{
  "version": 1,
  "background": "maps/layout/中原.png",
  "nodes": [
    {
      "id": "huashan",
      "x": 0.35, "y": 0.42,
      "w": 0.08, "h": 0.06,
      "click_zones": [
        { "x": 0.34, "y": 0.40, "w": 0.10, "h": 0.10 }
      ],
      "zoom_min": 1,
      "zoom_max": 2
    }
  ],
  "edges": [
    {
      "from": "huashan", "to": "huashan_inn",
      "path": [
        { "x": 0.40, "y": 0.43 },
        { "x": 0.45, "y": 0.44 },
        { "x": 0.49, "y": 0.46 }
      ]
    }
  ],
  "sub_maps": {
    "songshan": "songshan.json"
  }
}
```

## UI 布局

```
┌─────────────────────────────────────────────────────────┐
│  菜单栏：文件 │ 导出 │ 导入 │ 视图 │ 帮助                │
├─────────────────────────────────────────────────────────┤
│  面包屑：中原 > 嵩山 > [子地图]    [切换模式 B]  [⛭]   │
├──────────────┬────────────────────────────────┬─────────┤
│              │                                │   属性   │
│  Tag 池      │      Vue Flow 画布             │   面板   │
│  ┌────────┐  │                                │         │
│  │ martial│  │   节点（可拖拽、可多选）          │   节点ID │
│  │ sword  │  │   边（点选/双击/右键）            │   name  │
│  │ rest   │  │   层级折叠                       │   type  │
│  │ ...    │  │   缩放 / 平移                    │   tags  │
│  └────────┘  │                                │   parent│
│  输入+拖拽   │                                │ visible │
│  到节点赋值  │                                │         │
│              │                                │   边属性 │
│              │                                │   from  │
│              │                                │   to    │
│              │                                │  耗时   │
│              │                                │  方向   │
│              │                                │  条件   │
│              │                                │         │
├──────────────┴────────────────────────────────┴─────────┤
│  状态栏：选中 1 个节点 | 共 45 个节点 | 62 条边          │
└─────────────────────────────────────────────────────────┘
```

### 布局说明

- **左侧面板**：Tag 池。固定宽度 200px
- **中央画布**：Vue Flow，填满剩余空间
- **右侧面板**：上下文属性面板。选中节点显示节点属性，选中边显示边属性。固定宽度 280px
- **顶部开关**：模式 A/模式 B 切换、导出按钮
- **面包屑**：显示当前编辑的地图层级，可点击跳转

## 技术栈

| 层 | 技术 | 理由 |
|----|------|------|
| 框架 | Vue 3 + TypeScript | 与游戏同栈，降低心智负担 |
| 构建 | Vite | 与游戏同工具 |
| 画布 | Vue Flow | 成熟、类型完善、支持自定义节点/边 |
| 桌面壳 | Tauri | 5MB，原生文件读写，轻量 |
| TOML 解析 | @iarna/toml | 与游戏同库 |
| 状态管理 | Pinia | 与游戏同库，但允许不需要时不用 |

## 与游戏的对接

| 数据方向 | 桥梁 | 路径 |
|---------|------|------|
| 工具 → 游戏 | 导出 TOML | 工具 `export/` → 复制到 `mod/武侠/maps/` |
| 游戏 → 工具 | 导入 TOML | 工具打开时选择 mod 目录 → 解析 |
| 项目自身 | `.mapedit` JSON | 工具独立管理，不进入游戏目录 |
| 视觉数据 | `layout/*.json` | 工具导出，游戏 MapView 读取 |

工具导出目录的结构与游戏期待的 `maps/` 目录结构完全一致，可直接覆盖。

## 开发步骤

### 阶段 1：搭建骨架

1. `npm create tauri-app` 初始化项目
2. 安装 Vue Flow: `npm install @vue-flow/core`
3. 左右中三栏布局
4. 文件 → 新建 / 打开项目 / 保存
5. 导入游戏 TOML → 在画布上渲染节点树 + 边
6. 导出 TOML

### 阶段 2：编辑功能

7. 添加/删除节点（Tab 建子节点、双击建根节点）
8. 拖拽连线
9. 编辑节点属性（侧栏）
10. 编辑边属性（侧栏 + 单击/双击交互）
11. 右键菜单（删除、切换方向、切换显隐、创建子地图）
12. Tag 系统
13. 撤销/重做

### 阶段 3：视觉地图

14. 模式 B 开关 + 背景图支持
15. 比例坐标定位
16. 点击区域拖拽
17. 路径绘制
18. layout JSON 导出
