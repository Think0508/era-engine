## 2. 监禁流程

### 2.1 装袋 → 成为囚犯

1. 角色被装袋 (`be_bagged = True`)
2. 放入监狱 `chara_become_prisoner()`:
   - `be_bagged → False, imprisonment → True`
   - 换囚服(561+861)
   - 强制刻印:
     - 屈服刻印(ability[14]) → 至少LV2
     - 恐怖刻印(ability[17]) → 至少LV1
     - 反发刻印(ability[18]) → 至少LV3 (陷落可减轻)
   - 存入 `current_prisoners[character_id] = [game_time, 0]`

## 3. 逃脱机制

### 3.1 逃脱概率增长

```
escape_probability = (战力ability[42] + 学识ability[45]) × coefficient
coefficient = (生活水平setting[4] + 1) × 0.5 / 关押区设施效率
  - ability[14](屈服刻印) × 0.1
  + ability[18](反发刻印) × 0.2
  - 陷落等级 × 0.2
上限: (100 - existing) × 0.1, 最小1
```

### 3.2 逃脱判定

- 无监狱长: escape_probability > 30 → 成功
- 有监狱长: escape_probability > 50 + 设施修正(上限99)

```
escape_value = (escape_probability/100) × (setting[4]+1)×0.4 × ability[42] × hp% × mp%
warden_value = warden_ability[42] × hp% × mp%
若 escape_value > warden_value → 逃脱成功
```

### 3.3 逃脱成功

```
esaping = True → 角色离线 → 自动创建追捕外勤委托
```

## 4. 监禁H

**指令**: `IMPRISONMENT_H` (5051)

**关键差异**: 被监禁角色直接通过H同意, 无需实行值/陷落判定

**实时效果**:
```
被监禁中: 屈服(15) 和 恐怖(18) 持续增长 (3x时间 + 对应刻印修正)
```
