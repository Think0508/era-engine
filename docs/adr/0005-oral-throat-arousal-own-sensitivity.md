# 口喉欲情用自身感度（不复制 erArk 上游 bug）

2026-08-08 决策。erArk 源码中 TECH_ADD_M/F（口喉/兽部）的欲情结算传 `target_data.ability[7]`（子宫感度），与其他部位"自身感度"不一致（default.py:8178/8210）——明显的复制粘贴错误：M 应该用 ability[100]（口喉感度）、F 用 ability[101]（兽部感度）。若完整复刻会让口喉欲情吃子宫感度，数值荒谬且难排查。

决策：**修正为自身感度**（口喉欲情用口喉感度）。与"兽部全砍"叠加后实际只影响口喉。原则：引擎只复刻 erArk 的**设计意图**，不复制显然的源码 bug；偏离处一律注释 + ADR 记录，避免未来"对齐源码"时被误改回去。

权衡：数值与 erArk 实测有差异（口喉欲情系数不同），但意图一致（按被刺激部位的感度计算欲情）。曾考虑原样复刻（数值保真优先），因"架构合理清晰"原则（用户明确要求）与 bug 的可辨识性否决。

Status: accepted
