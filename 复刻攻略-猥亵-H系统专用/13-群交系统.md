# 群交系统

> 本文档描述群交(group sex)的启动、模板系统、NPC AI行为、HP/MP修正、多人结算机制。

---

## 1. 数据结构

`h_state.group_sex_body_template_dict` (game_type.py:424):
```
{
  "A": {  # 模板A
    "mouth": [character_id, behavior_id],
    "L_hand": [character_id, behavior_id],
    "R_hand": [character_id, behavior_id],
    "penis": [character_id, behavior_id],
    "anal":  [character_id, behavior_id],
    侍奉组: [[角色id列表], 行为id],
  },
  "B": { ... },  # 模板B (轮流模式)
}
```

每个身体部位只能有一个占有者。「插入」与「侍奉」互斥。

## 2. 启动

**指令**: `ASK_GROUP_SEX` (5055)

**前提**: `HAVE_TARGET | SCENE_ALL_NOT_H | SCENE_OVER_TWO | SCENE_ALL_NOT_TIRED | TIRED_LE_74`

**判定**: 对场景中每个NPC执行「群交」实行判定:
- 全部通过 → 进入ASK_GROUP_SEX + 每个NPC JOIN_GROUP_SEX
- 任一失败 → ASK_GROUP_SEX_FAIL，记录拒绝者

---

## 3. 模板操作

### 3.1 自动更新

默认 unlocked mode (`group_sex_lock_flag = False`): 玩家每次H行为 → 模板自动对应槽位分配

### 3.2 锁定模式

`group_sex_lock_flag = True` → 模板仅手动编辑

### 3.3 轮流模式

`all_group_sex_temple_run = True` → 模板A+B轮换执行

## 4. NPC AI (npc_ai_type_in_group_sex)

| 类型 | 行为 |
|------|------|
| 0 (Idle) | 无行动, 锁定WAIT |
| 1 (Self) | 自慰 (masturebate=3) |
| 2 (Auto-fill) | 优先补空位 → 无空位则自慰 |
| 3 (Random grab) | 随机填满空位 + 50%概率随机替换已占位 |

---

## 5. HP/MP修正

```
群交中: 玩家 HP/MP消耗 × 1/3, NPC × 1/2
例: degree=1基础 HP=3/min → 玩家1.0/min, NPC 1.5/min
```

### 5.1 HP耗尽

- NPC HP≤1: 触发GROUP_SEX_NPC_HP_0_END
  - 若剩余1NPC → 转为1v1 H
  - 若剩余0NPC → 群交结束
- 玩家 HP≤1: 群交结束

---

## 6. 多人结算

### 6.1 玩家行为结算

玩家一次行为 = 遍历模板A(及B)所有分配 → 逐个切换target + behavior → 全结算

### 6.2 状态加成

```
other_npc_num = min(10, scene_charas - 2)
积极状态加成: +0.05 × other_npc_num (上限+0.5)
经验加成: +0.02 × other_npc_num (上限+0.2)
```

### 6.3 经验

```
每次行为: experience[56](群交经验) +1
```

### 6.4 结束H结算

结束群交时遍历全场角色:
```
每角色:
  hit_point_max += 全部位绝顶次数 × 2
  mana_point_max += 全部位绝顶次数 × 3
  desire_point = max(desire_point - 绝顶次数 × 20, 0)
  玩家: semen_point_max += 绝顶次数(上限999)
  NPC: 能力升级检测
```
