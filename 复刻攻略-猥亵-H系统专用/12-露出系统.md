# 露出系统

> 本文档描述露出H(exhibitionism)的等级、启动、动态模式切换、被发现机制及结算效果。

---

## 1. exhibitionism_sex_mode 等级

`sp_flag.exhibitionism_sex_mode: int` — 0~4:

| 值 | 名称 | 条件 |
|----|------|------|
| 0 | 否 | 非露出 |
| 1 | 无人室内 | 仅2人 + 室内 + 门未锁 |
| 2 | 无人室外 | 仅2人 + 室外 |
| 3 | 人前露出 | >2人 + 至少1人有意识 |
| 4 | 无意识人前 | >2人 + 其他人全部无意识/睡眠 |

---

## 2. 启动

**指令**: `ASK_EXHIBITIONISM_SEX` (5054)

**前提**: `HAVE_TARGET | NOT_H | EXHIBITIONISM_SEX_MODE_0 | NO_TARGET_OR_TARGET_CAN_COOPERATE | TIRED_LE_74`

**实行判定**: 露出类, 基准值 500 (InstructJudge.csv)

**修正** (instuct_judege.py):
```
场景其他人惩罚: 40 + 40 × other_count (S类指令)
修正系数: (ability[34]的adjust - 1.6) × judge_other_people
ability[34]=0: adjust=0.5 → -1.1×惩罚 (更难)
ability[34]=7: adjust=1.5 → -0.1×惩罚 (容易)
```

---

## 3. 动态模式切换

每次行为循环自动重评估 (`update_exhibiionism_sex_mode()`):

```
若场景>2人 → 3(有意识)或4(无意识)
若场景=2人 → 1(室内)或2(室外)
```

---

## 4. 被发现的处理

**触发**: NPC进入场景 + 目睹露出H → `Sex_Be_Discovered_Panel`

5个选项:
1. 话术支开 → 实行判定「目击H后被话术支开」
2. 转为隐奸 → 调用Select_Hidden_Sex_Mode_Panel
3. 转为露出/继续 → 实行判定「露出」→ NPC无视或离开
4. 邀请群交 → 实行判定群交
5. 结束H → 尴尬结束

---

## 5. 结算效果

### 5.1 实时羞耻/快感

```
羞耻(16)增加: true_add_time × 3 × ability[34]修正 × others修正
心理快感(23)增加: 同上
others修正: min((others_count - 2) × 0.1, 2) (上限2.0)
```

### 5.2 露出经验

```
每次行为: experience[34](露出经验) +1
```

### 5.3 结束露出H

清除 `exhibitionism_sex_mode = 0`, 成就结算。
